# NDS Icon Maker

App Windows con interfaccia grafica per convertire un'immagine PNG in un `icon.bmp`
adatto a progetti Nintendo DS.

## Output
- 32x32 pixel
- BMP Windows V3
- 4 bit per pixel
- palette a 16 colori
- trasparenza riservata nel colore palette 0

## Avvio rapido
Doppio click su `run.bat`.

## Creare un .exe
Doppio click su `build_exe.bat`.

L'EXE verrà creato in:
`dist\NDSIconMaker.exe`

## Uso
1. Clicca **Scegli PNG**
2. Controlla l'anteprima NDS
3. Clicca **Esporta icon.bmp**
4. Salva il file nella root/cartella prevista dal tuo progetto NDS
